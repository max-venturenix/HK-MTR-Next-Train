# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users and purpose

Hong Kong commuters checking the next MTR train at familiar stations. Favorites are the opening screen; station search serves new journeys. Traditional Chinese is the interface language.

## Capabilities and constraints

Expo SDK 58, React Native, Expo Router and React Native Paper. Preserve station codes, line colors, API behavior, focus-aware polling and AsyncStorage `favorite_station_list` as a JSON string array. Support iOS, Android and functional web. Preserve native back gestures and accessible text scaling.

## Brand commitments

Material controls and train/star icons. System Chinese typography. The approved redesign replaces the oversized logo and blue header. Follow system light/dark appearance.
